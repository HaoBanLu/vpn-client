# 开发指南

## 开发环境搭建

### 前置要求

- Go 1.25+
- Docker & Docker Compose
- PostgreSQL 15+
- Redis 7+
- Node.js 18+（管理后台 / 会员 Web / Tauri）

### 本地开发环境

1. **克隆项目**
```bash
git clone <repository-url>
cd vpn
```

2. **启动依赖服务**
```bash
docker compose up -d postgres redis
```

3. **配置环境变量**
```bash
cp .env.example .env
# 编辑 .env 文件，配置数据库、Redis等连接信息
```

4. **初始化数据库**
```bash
# Docker 环境
docker compose exec -T postgres psql -U postgres -d vpn < migrations/init.sql

# 或本地 psql 连接 45432 端口
psql -h localhost -p 45432 -U postgres -d vpn -f migrations/init.sql
```

> 当前 MVP 使用 `migrations/init.sql`（幂等），不使用分散的 `010_*.sql` 文件。

5. **启动后端服务**（推荐 Docker 全栈；或本机）
```bash
# 推荐：整栈
docker compose up -d

# 或本机跑 API（勿把编译出的 api/api.exe 提交进 Git）
go run ./cmd/api
# 或
make run
```

6. **启动前端服务**
```bash
cd frontend/admin
npm install
npm run dev
```

## 代码规范

### Go 代码规范

- 遵循 [Effective Go](https://go.dev/doc/effective_go) 和 [Go Code Review Comments](https://github.com/golang/go/wiki/CodeReviewComments)
- 使用 `gofmt` 格式化代码
- 使用 `golint` 和 `golangci-lint` 进行代码检查
- 使用 `go vet` 进行静态分析

### 命名规范

- **包名**: 小写，简短，有意义
- **函数名**: 驼峰命名，公开函数首字母大写
- **变量名**: 驼峰命名，简短有意义
- **常量**: 全大写，下划线分隔

### 错误处理

- 所有错误必须被处理，不能忽略
- 使用 `errors.Wrap` 包装错误，保留堆栈信息
- 自定义错误类型，使用 `errors.New` 或 `fmt.Errorf`

### 日志规范

- 使用结构化日志（如 `logrus` 或 `zap`）
- 日志级别：DEBUG, INFO, WARN, ERROR
- 敏感信息（密码、token）不能记录到日志

## 管理后台移动端适配

管理后台已支持手机浏览器访问。移动端适配集中在 `frontend/admin/src/layouts/BasicLayout.vue`、`frontend/admin/src/style.css` 和各业务页面的卡片列表实现中维护。

### 适配原则

- 手机断点以 `767px` 为界，未显式设置 `xs` 的栅格列在手机端按单列展示。
- 列表页优先使用「桌面表格 + 手机卡片」模式；未单独实现卡片的表格使用 `.admin-auto-mobile-table` 自动转字段卡片。
- 手机侧栏使用固定定位和遮罩，打开时锁定页面滚动，侧栏内部可滚动；点击叶子菜单或遮罩后关闭。
- 页面内容区在手机端保留底部留白和 `safe-area-inset-bottom`，避免滚到底时内容贴近屏幕底部。

### 验收建议

- 使用浏览器 390px 左右宽度模拟手机视口，覆盖 `/dashboard`、订单、用户、节点、工单、财务、系统设置等主要后台页面。
- 每个页面需要检查顶部、列表区域和滚动到底部，确认无横向溢出、无表格挤压成窄列、最后一屏有足够底部间距。
- 涉及侧栏或菜单时，检查展开父菜单、侧栏内滚动、点击叶子菜单跳转后的关闭行为。
- 修改后至少执行 `npm run build`，并在浏览器里验证关键移动端页面。

## Git 工作流

### 分支策略

- `main`: 主分支，生产环境代码
- `develop`: 开发分支
- `feature/*`: 功能分支
- `fix/*`: 修复分支
- `release/*`: 发布分支

### 提交规范

使用 [Conventional Commits](https://www.conventionalcommits.org/) 规范：

```
feat: 添加用户注册功能
fix: 修复登录验证码错误
docs: 更新部署说明
refactor: 重构订单服务
test: 添加用户服务测试
chore: 更新依赖版本
```

## 常见问题

### 数据库连接失败

检查 `.env` 文件中的数据库配置，确保 Docker 容器正常运行。

### 端口被占用

修改 `docker-compose.yml` 中的端口映射，或停止占用端口的服务。

### 依赖安装失败

使用国内镜像源：
```bash
go env -w GOPROXY=https://goproxy.cn,direct
```
