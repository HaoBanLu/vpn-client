# 开发指南（vpn-client）

本仓为 **会员客户端**。控制面（API / admin / 节点）在 **`vpn`** 仓库。

## 前置

- Node.js 22+
- Rust（桌面 / Android Tauri）
- Android SDK + NDK（打 Android 包）
- JDK 17（Android）

## 工程

| 路径 | 说明 |
|------|------|
| `apps/tauri` | **主工程**：Win/Mac/Linux + Android + iOS |
| `apps/android` | **存档**；仅 `mihomo-core` 供 Tauri 链接 |

包名统一：**`com.vpn.kuayun`**（iOS 为 `.app` / `.tunnel`）。

## 常用命令

```bash
cd apps/tauri
npm run setup                 # 依赖 + mihomo
npm run tauri:dev             # Windows 桌面（可测 VPN）
npm run dev                   # 仅浏览器 UI
npm test
npm run tauri:android:build:release
```

API 地址：开发用 `.env.development`；正式包用 GitHub Secret `VITE_API_BASE_URL`。
