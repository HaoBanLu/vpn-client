# App 企业级差距清单（对标商业 VPN）

> **核心结论**：跨云 Android App 已达 **「可商用 MVP+」**（控制面一体化 + Mihomo TUN + 稳定性 P0–P3 骨架），但距 **ExpressVPN / NordVPN / 快帆** 一线消费级产品，仍差 **连接可信度可证明、质量门禁自动化、多平台与运营闭环**；距 **Zscaler / AnyConnect** 类 B2B 企业套件更远。**默认发版继续使用全量 APK（~49MB）**，瘦包仅作可选方案。  
> **文档状态**：进行中  
> **最后更新**：2026-07-01  
> **关联**：[App成熟化产品路线](App成熟化产品路线.md)、[功能todo.md](../功能todo.md)、[自研App稳定性评估与优化方案](自研App稳定性评估与优化方案.md)

---

## 1. 定位说明

| 层级 | 含义 | 跨云现状 |
|------|------|----------|
| **消费级商业 VPN** | ExpressVPN、NordVPN、Mullvad、快帆 | **主要对标**；综合约 **3.5 / 5** |
| **机场/代理客户端** | CMFA、v2rayNG | 内核与热重载已对齐；控制面集成更强 |
| **B2B 企业 VPN** | Zscaler、Cisco AnyConnect、Tailscale 企业版 | **不在当前范围**；无 SSO/MDM/合规套件 |

**生产级认定标准**（与成熟化路线一致）：P0 全部完成 + **7 日崩溃率 ≤0.5%** + **真机 ROM 矩阵通过率 ≥90%** + 曼谷回国 KPI ≥12/15。

---

## 2. 已具备能力（不必重复建设）

| 类别 | 能力 |
|------|------|
| 连接 | Mihomo TUN、`/client/config`、热重载、url-test、回国/海外 Profile、节点 failover |
| 稳定 | 断网自动重连、Kill Switch、IPv6 防护、鉴权断开、Service/崩溃恢复、周期探测、30s 连接超时 |
| 隐私 | 连接与隐私页、泄露自检与历史、保护等级、登出阻断、重连期不裸连（默认） |
| 控制面 | 订阅/套餐校验、坏节点过滤、诊断日志 + 后台筛选、连接耗时/API 错误采样 |
| 通知 | 本地系统通知 P0；FCM Token + 服务端发送 + 充值推送（需生产联调） |
| 工程 | `release-gate.sh`、发版清单、仪器化冒烟、弱网脚本（可选） |

## 3. 与企业级差距（按优先级）

### 3.1 P0 — 连接可信度（「敢不敢宣称生产级」）

| ID | 差距 | 企业级期望 | 现状 | 验收 |
|:--:|------|------------|------|------|
| G-P0-1 | 曼谷/回国场景批量验收 | 核心场景可达率 ≥80% | 脚本有，**未纳入发版必过** | `ssh_debug/test_bangkok_cn_nodes_domestic_return.py` ≥12/15 |
| G-P0-2 | 「已保护」与数据面一致 | 误报率极低，可审计 | 逻辑已加强，**缺 7 日真机统计** | 诊断 `tun_tcp_log` / 保护等级变更埋点 |
| G-P0-3 | 首连 P95 | <5s SLA | 有 `ConnectTimingArchive` + 后台采样 | 发版对照 KPI，未硬阻断 |
| G-P0-4 | ROM 真机矩阵 | 20 款主流 ROM 抽测 | JSON + gate；**1/5 通过** | 🚧 2026-07-01 |

### 3.2 P1 — 质量门禁与可观测

| ID | 差距 | 企业级期望 | 现状 | 验收 |
|:--:|------|------------|------|------|
| G-P1-1 | 崩溃率发版门槛 | 7 日 ≤0.5%，超标不发版 | API + 后台卡片 + gate 提示 | 🚧 2026-07-01 |
| G-P1-2 | 崩溃聚合告警 | Crashlytics/Sentry 全量 | 可选 `app_debug_logs`，**无告警** | 接入 Firebase Crashlytics 或等价 |
| G-P1-3 | CI 真机门禁 | 每版仪器化 + 弱网回归 | `android-ci.yml` PR + nightly | 🚧 2026-07-01 |
| G-P1-4 | API 全链路 SLO | Prometheus 告警、灰度回滚 | 采样 ✅，**告警/门禁无** | 见 [App接口稳定性治理需求文档](App接口稳定性治理需求文档.md) |
| G-P1-5 | 连接成功率仪表盘 | 运营可视 + 尖峰告警 | 部分 API 已有 | 首连成功率、自动重连成功率聚合 |

### 3.3 P2 — 体验与产品完整度

| ID | 差距 | 企业级期望 | 现状 |
|:--:|------|------------|------|
| G-P2-1 | 分应用代理热更新 | 改规则不断 TUN | 常需 **重连** |
| G-P2-2 | 应用内消息中心 | 公告/系统消息列表 | **无**；靠通知栏 + 角标 |
| G-P2-3 | FCM 生产闭环 | 到期/充值/公告模板 + E2E | 脚手架 ✅，**Firebase 凭证 + 真机未验** |
| G-P2-4 | 安装包体积 | 商店 AAB / 按需下发 | **全量 arm64 ~49MB**（默认）；瘦包可选 |
| G-P2-5 | 多 VPN 并存提示 | 检测企业 VPN 冲突 | PRD R-14，**未实现** |
| G-P2-6 | Always-On / Lockdown | 一键托管或强引导 | 跳转系统设置 + 检测，**非全自动** |

### 3.4 P3 — 平台与 B2B（长期）

| ID | 差距 | 说明 |
|:--:|------|------|
| G-P3-1 | iOS 原生 | 仅规划 |
| G-P3-2 | 桌面与 Android 体验对齐 | Tauri 有，未统一 KPI |
| G-P3-3 | App 内原生 OV/WG | 有意不做；企业采购偶发要求 |
| G-P3-4 | SSO / MDM / 团队审计 | B2B 套件，非消费级范围 |
| G-P3-5 | 专属 IP、威胁防护等增值 | Nord 等差异化，非核心 |

## 4. 能力评分（5 分制）

| 维度 | 分数 | 说明 |
|------|:----:|------|
| 首次连接 | 4 | 正常网络链路完整 |
| 断网/换网恢复 | 3.5 | 已实现，真机矩阵待验 |
| 隐私防泄露 | 4 | 默认策略已对齐商业 VPN |
| 弱网/长期在线 | 3.5 | degraded + failover；投诉数据待证 |
| 可观测与发版门禁 | 3 | 工具有，未全自动阻断 |
| 多平台 | 2 | Android 为主 |
| 运营触达 | 3 | P0 通知 + FCM 半成品 |
| **综合** | **≈3.5** | 可上线运营，不宜称「企业级标杆」 |

## 5. 建议实施顺序（写入成熟化 backlog）

| 优先级 | ID | 动作 | 产出 |
