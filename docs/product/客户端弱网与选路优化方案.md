## 1. 核心结论

**应在控制面订阅与自研 App 配置中补齐「自动选路（url-test/urltest）+ 故障转移 + 海外弱网 DNS/TUN Profile」三层能力**，使 Clash Meta、sing-box 客户端、自研 App 与行业机场订阅体验对齐；缅甸等用户默认推荐新加坡直连节点，双跳中转节点不进入自动选路池。

**实施顺序**：先改订阅与 `/client/config`（P0，后端为主）→ 再改 App 测速/探测/重连（P1）→ 最后做 GEOIP 规则集与运营看板（P2）。

## 2. 背景与问题（SCQA）

> **历史说明（2026-07-01）**：§2.1 及以下正文写于 **Mihomo 迁移前**（sing-box/libbox）。当前自研 App 已统一 `GET /client/config` → **Clash YAML + Mihomo TUN**（2026-06-22）。**`client_markets` 已废弃**；未完成项见 [App成熟化产品路线](App成熟化产品路线.md)。

### 2.1 情景（Situation）

- 控制面已支持多格式订阅：Clash、V2Ray、SS、Trojan、WG、OpenVPN（~~sing-box 订阅已移除~~）
- 自研 Android App 通过 `GET /api/v1/client/config` 拉 **Clash YAML**，Mihomo + TUN 全量代理
- 后台 `/settings/client-runtime` 可统一配置 DNS、TUN stack、sniff 等参数
- 节点支持直连与 L4 中转（如贵州经香港 CN2、新加坡 BGP 直连）

### 2.2 冲突（Complication）

弱网实测（Clumsy：300ms 延迟 + 2% 丢包 + 1.5Mbps 限速）与代码审查发现：

| 现象 | 根因 |
|------|------|
| 缅甸刷视频卡 | 用户连贵州/武汉（高 RTT 或双跳），而非新加坡 |
| 「智能选路」不智能 | 配置仅 `selector`，`default` = 列表第一个节点，**无 urltest** |
| Clash 订阅像「节点列表」 | proxy-groups 只有 `select`，**无 url-test / fallback** |
| App 显示延迟不准 | 测速为控制面 TCP 连**出口 IP**，非用户到**订阅入口** |
| 弱网误报不可用 | `ConnectivityProbe` 固定 8s 超时；DNS `FLAG_NO_RETRY` |
| 与 Clash Meta / v2rayNG 体验差距大 | 缺自动选路、规则分流、客户端真实测速 |

### 2.3 疑问（Question）

后台管理中心与自研 App 应如何优化？与 Clash、Shadowrocket、sing-box、v2rayNG 相比少什么？按什么顺序实现？

### 2.4 答案（Answer）

本方案分 **P0 / P1 / P2** 三阶段，优先改**订阅链接内容**与 **App 配置生成**（投入小、三端同时受益），再改 App 客户端逻辑，最后补运营与可观测性。

## 5. 方案设计

### 5.0 节点地区 vs 客户端市场（2026-06 拆分）

| 概念 | 数据表 | 后台入口 | 用途 |
|------|--------|----------|------|
| **节点地区** | `regions` | 系统设置 → 节点地区 | 节点在哪（sg/hk/cn），创建节点时选择 |
| **客户端市场** | `client_markets` | 系统设置 → 客户端市场 | 用户在哪（如缅甸 mm），映射节点池 + 弱网策略 |

订阅/App 参数：`market=mm`（推荐）；`region=mm` 仍兼容。`region=sg` 仍表示按**节点地区**筛选。

### 5.1 配置 Profile 体系（后台）

在 `client_runtime` 上扩展 **场景 Profile**，避免「回国优化」与「海外弱网」互相打架。

| Profile | 适用用户 | DNS final | TUN stack | sniff | 说明 |
|---------|----------|-----------|-----------|-------|------|
| `domestic_return`（默认） | 海外连回国 | direct | mixed | on | 保持现状 |
| `overseas_weak` | 缅甸、东南亚看海外视频 | remote | system | off | 新建 |
| `custom` | 运维手动 | 后台表单 | 后台表单 | 后台表单 | 已有 |

**下发逻辑**：

- `GET /client/config`：query `market`（推荐）或 `region`（兼容）选择节点池；`profile=` 选择连接场景（如 `overseas_weak`）
- 订阅生成（Clash/sing-box）：共用同一 `effectiveRuntime()`，与 App 一致

**后台 UI**（`/settings/client-runtime`）：

- 增加「配置模板」Tab：一键切换 `domestic_return` / `overseas_weak`
- 增加「海外弱网说明」Alert
- 保存前展示 diff

### 5.2 订阅链接优化（Clash）

**文件**：`internal/service/subscription_clash_template.go`

在现有 `手动选择` 之上增加：

```yaml
proxy-groups:
  - name: 自动选择
    type: url-test
    url: https://www.gstatic.com/generate_204   # 海外弱网 profile 可配置
    interval: 300
    tolerance: 80
    proxies: [新加坡-BGP线路, 香港, ...]        # 排除双跳「仅回国」节点

  - name: 故障转移
    type: fallback
    url: https://www.gstatic.com/generate_204
    interval: 300
    proxies: [自动选择, 新加坡-BGP线路, ...]

  - name: Proxy
    type: select
    proxies: [自动选择, 故障转移, 手动选择, DIRECT]
```

**规则调整**（P1）：

- `mode: rule`（可配置，海外 profile 默认 rule）
- 保留现有 DOMAIN-KEYWORD 规则
- 后续 P2 接入 `rule-providers`（geosite/geoip）

**节点分组策略**：

| 节点类型 | 进入自动选择池 | 说明 |
|----------|:--------------:|------|
| 海外直连（sg/hk/jp） | ✅ | 缅甸默认 |
| 双跳中转（贵州等） | ❌ | 仅「手动选择」 |
| 中国大陆出口 | ❌（海外 profile） | 提示「适合回国」 |

### 5.3 订阅链接优化（sing-box）

**文件**：`internal/service/subscription_generator.go`、`subscription_dual_endpoint.go`

新增 outbounds：

```json
{
  "type": "urltest",
  "tag": "自动选择",
  "outbounds": ["新加坡-BGP线路", "..."],
  "url": "https://www.gstatic.com/generate_204",
  "interval": "5m",
  "tolerance": 80
}
```

- `route.final` / selector `default` → `自动选择`（智能选路时）
- 指定 `node` 参数时行为不变，仍固定该节点

### 5.4 自研 App 配置（`/client/config`）

与 sing-box 订阅对齐，**必须**包含 urltest（修改 `subscription_generator_app_test.go` 断言）。

额外 App 专属优化（`apps/android`）：

| 项 | 文件 | 改动 |
|----|------|------|
| DNS 弱网重试 | `vpn/libbox/VpnLocalResolver.kt` | 去掉 `FLAG_NO_RETRY` 或封装重试 |
| 探测超时 | `vpn/ConnectivityProbe.kt` | 8s → 20s，分阶段探测 |
| 探测文案分级 | `ui/viewmodel/ConnectViewModel.kt` | 区分「隧道已建立 / 探测慢 / 不可用」 |
| 客户端测速 | 新增 `ClientLatencyProbe.kt` | TCP 连**订阅入口** server:port |
| 节点场景提示 | `ui/screens/NodesScreen.kt` | 新加坡=海外视频；贵州=回国 |
| 弱网自动重连 | `vpn/VpnTunnelService.kt` | 断线最多 2 次 reconnect（P1） |
| split 分流 | `vpn/AppRouteMode.kt` | 海外弱网 profile 自动 `split`；`cn`/空 → `full`；**连接页无开关**（2026-06-18） |
| App 诊断日志 | `debug/AppDebugLogger.kt` | 后台对用户开启后采集连接/探测/sing-box 日志并上报 |

### 5.5 节点测速 API

**文件**：`internal/service/node_test_service.go`

| 现状 | 目标 |
|------|------|
| `net.Dial` 到 `node.IPAddress:port`（出口） | `resolveSubscriptionEndpoint(node)` 的入口地址 |
| 仅返回一个 latency | 可选返回 `entry_ms`、`exit_ms` |

App `NodesViewModel` 测速改为调用新字段或本地探测入口。

### 5.6 运营配置（后台）

| 能力 | 位置 | 说明 |
|------|------|------|
| 节点场景标签 | 节点列表/编辑 | `nodes.scene_tags_manual`（如「适合海外视频」） |
| **客户端市场** | 系统设置 → **客户端市场** | 用户所在地区（如缅甸 `mm`）→ `node_pool_regions`（sg/hk）、偏好订阅类型、默认 Profile |
| **节点地区** | 系统设置 → **节点地区** | 仅节点机房地区（sg/hk/cn），创建节点时选择；**不含缅甸** |
| 客户端配置模板 | `/settings/client-runtime` | 海外弱网一键切换 |
| **App 调试** | 用户管理 → 会员列表/详情 | `users.app_debug_enabled`；开启后 App 显示「诊断日志」并上报 `app_debug_logs` |

### 5.7 App 诊断日志（按用户开关）

**结论**：普通用户零干扰；客服对指定用户开启调试后，App 本地可查看日志，后台会员详情可远程查看。

| 环节 | 说明 |
|------|------|
| 开关 | 管理后台会员列表「App 调试」列 / 编辑账号 / 详情 Switch → `PUT /admin/users/:id` |
| App 采集 | 连接、探测、sing-box、心跳失败等；脱敏后批量上报 |
| App 入口 | **我的 → 诊断日志**（仅调试用户）；连接异常时出现「查看诊断日志」 |
| 后台查看 | 会员详情 → **App 诊断日志**（筛选级别、复制最近 50 条） |
| API | `POST /users/me/app-debug-logs`；`GET /admin/users/:id/app-debug-logs` |
| 保留 | 每用户最多 500 条或 7 天；未开启调试时 POST 403 |

## 8. 风险与回滚

| 风险 | 缓解 |
|------|------|
| urltest 增加节点探测流量 | interval ≥ 300s，tolerance 80ms |
| 关 sniff 导致少数 App 路由异常 | 仅 `overseas_weak` profile；回国保持 sniff on |
| 改 DNS 为 remote 影响回国用户 | Profile 隔离，默认仍 `domestic_return` |
| 旧版 App 不识别 urltest | libbox 1.0.1 已支持；发版说明要求升级 |
| 测试断言变更 | 同步改 `subscription_generator_app_test.go` |

**回滚**：后台 `client-runtime` 切回 `domestic_return`；代码 feature 可用环境变量 `AUTO_SELECT_ENABLED=false`（实现时添加）。
